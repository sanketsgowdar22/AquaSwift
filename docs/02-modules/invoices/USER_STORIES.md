# Invoices Module — User Stories

## US-INVC-001: Admin Generates Invoice

**As a** super admin (P5), **I want to** generate a consolidated invoice for a business covering a billing period, **So that** B2B customers receive formal billing documentation.
**SRS Requirements:** INVC-001, INVC-002 **Priority:** MUST **Phase:** Phase 2

---

## US-INVC-002: Invoice PDF Generation

**As a** system, **I want** invoices to be generated as PDF documents stored in S3, **So that** they can be downloaded and emailed to the business.
**SRS Requirements:** INVC-003 **Priority:** MUST **Phase:** Phase 2

---

## US-INVC-003: Invoice Status Tracking

**As a** super admin (P5), **I want to** track invoice payment status (PENDING/PAID/OVERDUE), **So that** I can manage accounts receivable.
**SRS Requirements:** INVC-004, INVC-005 **Priority:** MUST **Phase:** Phase 2
