# Addresses Module — User Stories

## US-ADDR-001: Customer Address Management

**As a** customer (P1),
**I want to** add, edit, and delete my delivery addresses with auto-geocoding,
**So that** I can manage multiple delivery locations and provide accurate GPS coordinates.

**SRS Requirements:** ADDR-001, ADDR-002, ADDR-004
**Priority:** MUST
**Phase:** V1

---

## US-ADDR-002: Address Selection During Ordering

**As a** customer (P1),
**I want to** select a saved address or add a new one during order placement,
**So that** I can quickly place orders to any of my locations.

**SRS Requirements:** ADDR-003
**Priority:** MUST
**Phase:** V1

---

## US-ADDR-003: Admin Address Management

**As an** admin (P4/P5),
**I want to** view and manage customer addresses,
**So that** I can assist with delivery issues and correct address problems.

**SRS Requirements:** ADDR-005
**Priority:** MUST
**Phase:** V1

---

## US-ADDR-004: Business Site Management

**As a** business admin (P2),
**I want to** manage delivery sites for my business,
**So that** orders can be placed for specific project locations.

**SRS Requirements:** ADDR-006, ADDR-007
**Priority:** MUST (schema V1), COULD (UI Phase 2)
**Phase:** V1 (schema) / Phase 2 (UI)
