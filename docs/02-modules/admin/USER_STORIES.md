# Admin Module — User Stories

## US-ADM-001: Admin Dashboard Summary

**As an** admin (P4/P5),
**I want to** see a dashboard with key metrics and alerts,
**So that** I have an at-a-glance view of operations.

**SRS Requirements:** ADM-001, ADM-002
**Priority:** MUST
**Phase:** V1

---

## US-ADM-002: Role Management

**As a** super admin (P5),
**I want to** manage roles and permissions for platform users,
**So that** I can control who has access to what.

**SRS Requirements:** ADM-003
**Priority:** MUST
**Phase:** V1

---

## US-ADM-003: Admin Catalog/Pricing Configuration

**As a** super admin (P5),
**I want to** configure catalog entries and pricing rules via the admin dashboard,
**So that** the platform is configurable without code changes.

**SRS Requirements:** ADM-004, ADM-005
**Priority:** MUST
**Phase:** V1
