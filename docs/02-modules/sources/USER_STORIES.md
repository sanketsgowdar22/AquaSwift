# Sources Module — User Stories

## US-SRC-001: Admin Manages Water Sources

**As an** admin (P4/P5),
**I want to** create, view, update, and deactivate water sources,
**So that** I can manage supply points and their status.

**SRS Requirements:** SRC-001, SRC-002
**Priority:** MUST
**Phase:** V1

---

## US-SRC-002: Source Capacity & Status

**As an** admin (P4/P5),
**I want to** see each source's capacity and current status (ACTIVE/INACTIVE/MAINTENANCE),
**So that** I know which sources are available for inventory intake.

**SRS Requirements:** SRC-003, SRC-004
**Priority:** MUST
**Phase:** V1
