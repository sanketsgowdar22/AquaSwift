# Analytics Module — User Stories

## US-ANL-001: Order Trend Analytics

**As an** admin (P4/P5), **I want to** see order volume and revenue trends over time, **So that** I can identify growth patterns.
**SRS Requirements:** ANL-001 **Priority:** SHOULD **Phase:** Phase 2

---

## US-ANL-002: Customer Retention Analytics

**As an** admin (P4/P5), **I want to** see customer retention, repeat order rate, and churn metrics, **So that** I can improve customer engagement.
**SRS Requirements:** ANL-002 **Priority:** SHOULD **Phase:** Phase 2

---

## US-ANL-003: Delivery Efficiency Analytics

**As an** admin (P4/P5), **I want to** see delivery efficiency metrics (time, cost, routes), **So that** I can optimize logistics.
**SRS Requirements:** ANL-003 **Priority:** SHOULD **Phase:** Phase 2

---

## US-ANL-004: Inventory Forecasting

**As an** admin (P4/P5), **I want to** see inventory consumption forecasts, **So that** I can plan procurement.
**SRS Requirements:** ANL-004 **Priority:** COULD **Phase:** Phase 2

---

## US-ANL-005: Revenue Analytics Dashboard

**As an** admin (P5), **I want to** see revenue breakdowns by purpose, quality, customer type, and area, **So that** I can make strategic pricing decisions.
**SRS Requirements:** ANL-005 **Priority:** SHOULD **Phase:** Phase 2
