# Users Module — User Stories

## US-USR-001: Customer Profile Management

**As a** customer (P1),
**I want to** create and update my profile (name, email, phone),
**So that** my information is accurate for deliveries and communication.

**SRS Requirements:** USR-001, USR-005
**Priority:** MUST
**Phase:** V1

---

## US-USR-002: Driver Profile Management

**As a** driver (P3),
**I want to** create and update my profile (name, phone, vehicle info),
**So that** my information is current for assignments and communication.

**SRS Requirements:** USR-002
**Priority:** MUST
**Phase:** V1

---

## US-USR-003: Admin Customer Management

**As an** admin (P4/P5),
**I want to** view, search, and manage customer accounts,
**So that** I can support customers and manage the user base.

**SRS Requirements:** USR-003, USR-004, USR-006
**Priority:** MUST
**Phase:** V1
