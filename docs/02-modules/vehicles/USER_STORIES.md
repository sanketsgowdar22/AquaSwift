# Vehicles Module — User Stories

## US-VEH-001: Admin Manages Fleet

**As an** admin (P4/P5),
**I want to** create, view, update, and deactivate vehicles in the fleet,
**So that** I can manage available delivery capacity.

**SRS Requirements:** VEH-001, VEH-002, VEH-003
**Priority:** MUST
**Phase:** V1

---

## US-VEH-002: Vehicle-Driver Assignment

**As an** admin (P4/P5),
**I want to** assign and reassign drivers to vehicles,
**So that** each driver has a designated vehicle for deliveries.

**SRS Requirements:** VEH-004, VEH-005
**Priority:** MUST
**Phase:** V1
