# Businesses Module — User Stories

## US-BIZ-001: Admin Creates Business Account

**As a** super admin (P5), **I want to** create business accounts with registration details, **So that** B2B customers can be onboarded.
**SRS Requirements:** BIZ-001, BIZ-002 **Priority:** MUST **Phase:** V1 (backend) / Phase 2 (UI)

---

## US-BIZ-002: Business User Management

**As a** super admin (P5), **I want to** add users to businesses with admin/employee roles, **So that** businesses have role-based access.
**SRS Requirements:** BIZ-003, BIZ-004 **Priority:** MUST **Phase:** Phase 2

---

## US-BIZ-003: Business Site Management

**As a** business admin (P2), **I want to** manage delivery sites for my business, **So that** orders can target specific project locations.
**SRS Requirements:** BIZ-005, BIZ-006 **Priority:** MUST **Phase:** Phase 2

---

## US-BIZ-004: Business Dashboard

**As a** business admin (P2), **I want to** view orders, invoices, and usage for my business, **So that** I can manage operations and budgets.
**SRS Requirements:** BIZ-007 **Priority:** SHOULD **Phase:** Phase 2
