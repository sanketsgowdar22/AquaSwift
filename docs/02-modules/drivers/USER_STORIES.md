# Drivers Module — User Stories

## US-DRV-001: Driver Availability Toggle

**As a** driver (P3),
**I want to** toggle my availability status (AVAILABLE/UNAVAILABLE),
**So that** I only receive delivery offers when I'm ready to work.

**SRS Requirements:** DRV-001, DRV-002
**Priority:** MUST
**Phase:** V1

---

## US-DRV-002: Driver Delivery History

**As a** driver (P3),
**I want to** view my past deliveries with dates, quantities, and outcomes,
**So that** I can track my work history.

**SRS Requirements:** DRV-003
**Priority:** MUST
**Phase:** V1

---

## US-DRV-003: Driver Earnings

**As a** driver (P3),
**I want to** view my earnings summary (daily/weekly/monthly),
**So that** I can track my income.

**SRS Requirements:** DRV-004
**Priority:** MUST
**Phase:** V1

---

## US-DRV-004: Admin Driver Management

**As an** admin (P4/P5),
**I want to** create, view, update, and deactivate driver profiles,
**So that** I can manage the driver workforce.

**SRS Requirements:** DRV-005, DRV-006, DRV-007
**Priority:** MUST
**Phase:** V1
