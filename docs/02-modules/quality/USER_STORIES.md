# Quality Module — User Stories

## US-QUAL-001: Customer Views Quality Records

**As a** customer (P1),
**I want to** view approved water quality test records for my selected source/purpose,
**So that** I can verify the water meets safety standards before ordering.

**SRS Requirements:** QUAL-003
**Priority:** MUST
**Phase:** V1

---

## US-QUAL-002: Admin Manages Quality Records

**As an** admin (P4/P5),
**I want to** create, review, approve, and reject water quality test records with certificates,
**So that** all water sources maintain documented quality standards.

**SRS Requirements:** QUAL-001, QUAL-002, QUAL-004
**Priority:** MUST
**Phase:** V1
