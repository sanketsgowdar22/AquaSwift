# Bulk Orders Module — User Stories

## US-BULK-001: Business Submits Bulk Request

**As a** business admin (P2), **I want to** submit a bulk water request with quantity, frequency, and schedule, **So that** I can get a custom quote for large-scale supply.
**SRS Requirements:** BULK-001, BULK-002 **Priority:** MUST **Phase:** V1 (backend) / Phase 2 (UI)

---

## US-BULK-002: Admin Creates Bulk Quote

**As a** super admin (P5), **I want to** create a custom quote for a bulk request with negotiated pricing, **So that** I can offer competitive rates to large customers.
**SRS Requirements:** BULK-003, BULK-004 **Priority:** MUST **Phase:** V1 (backend) / Phase 2 (UI)

---

## US-BULK-003: Bulk Quote Acceptance

**As a** business admin (P2), **I want to** accept or reject a bulk quote, **So that** I can finalize the agreement before orders begin.
**SRS Requirements:** BULK-005 **Priority:** MUST **Phase:** Phase 2

---

## US-BULK-004: Bulk Order Generation

**As a** system, **I want** accepted bulk agreements to auto-generate individual orders per the schedule, **So that** deliveries happen without repeated manual ordering.
**SRS Requirements:** BULK-006, BULK-007 **Priority:** SHOULD **Phase:** Phase 2
