# Reviews Module — User Stories

## US-REV-001: Customer Submits Review

**As a** customer (P1),
**I want to** rate and comment on a completed order,
**So that** I can provide feedback on the delivery experience.

**SRS Requirements:** REV-001, REV-002
**Priority:** MUST
**Phase:** V1

---

## US-REV-002: Driver Views Reviews

**As a** driver (P3),
**I want to** see ratings and comments from my completed deliveries,
**So that** I can improve my service.

**SRS Requirements:** REV-003
**Priority:** SHOULD
**Phase:** V1

---

## US-REV-003: Admin Reviews Management

**As an** admin (P4/P5),
**I want to** view all reviews with filtering (by rating, driver, date),
**So that** I can monitor service quality.

**SRS Requirements:** REV-004
**Priority:** SHOULD
**Phase:** V1
