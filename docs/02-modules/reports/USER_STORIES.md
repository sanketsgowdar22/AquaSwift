# Reports Module — User Stories

## US-RPT-001: Sales Report

**As an** admin (P4/P5), **I want to** generate sales reports by period/purpose/quality, **So that** I can track revenue and volume.
**SRS Requirements:** RPT-001 **Priority:** MUST **Phase:** V1

---

## US-RPT-002: Inventory Report

**As an** admin (P4/P5), **I want to** generate inventory supply/consumption reports, **So that** I can manage procurement.
**SRS Requirements:** RPT-002 **Priority:** MUST **Phase:** V1

---

## US-RPT-003: Delivery Performance Report

**As an** admin (P4/P5), **I want to** generate delivery performance reports (avg time, success rate), **So that** I can optimize operations.
**SRS Requirements:** RPT-003 **Priority:** MUST **Phase:** V1

---

## US-RPT-004: Customer Metrics Report

**As an** admin (P4/P5), **I want to** generate customer reports (new/returning, order frequency), **So that** I can understand customer behavior.
**SRS Requirements:** RPT-004 **Priority:** SHOULD **Phase:** V1

---

## US-RPT-005: Scheduled Report Generation

**As a** system, **I want** reports to be pre-aggregated via Celery jobs, **So that** report queries are fast.
**SRS Requirements:** RPT-005 **Priority:** SHOULD **Phase:** V1
